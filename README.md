# AI News Analyzer

Веб-приложение для сбора, анализа и краткого представления новостей.

## Возможности

- получение новостей из источников;
- анализ и краткие сводки;
- настройка API;
- работа с несколькими экранами приложения;
- локальное хранение данных;
- обновление новостей;
- offline-сценарии;
- PWA-возможности.

## Стек

- HTML
- CSS
- JavaScript
- RSS/API
- PWA

## Структура

`js/api.js` — работа с API  
`js/rss.js` — RSS-источники  
`js/storage.js` — локальное хранение  
`js/ui.js` — интерфейс  
`js/app.js` — основная логика

## Статус

🟢 Самостоятельный веб-проект.
