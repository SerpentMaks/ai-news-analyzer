# AI News Analyzer 📰

> Клиентское веб-приложение для получения новостей из RSS/API-источников и их анализа через подключаемые AI-провайдеры.

## Архитектура

Логика разделена на отдельные модули:

- `api.js` — работа с API и AI-провайдерами;
- `rss.js` — получение и обработка RSS-лент;
- `storage.js` — локальное хранение состояния;
- `ui.js` — интерфейс;
- `app.js` — связывает основные части приложения.

Такой подход отделяет получение данных, AI-анализ, хранение и UI вместо одного монолитного скрипта.

## Технологии

- HTML5
- CSS
- JavaScript ES Modules
- Fetch API
- RSS
- Local Storage
- AI API providers

## Запуск

Статический frontend удобно запускать через локальный HTTP-сервер:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

Если выбранный AI-провайдер требует API-ключ, его необходимо настроить в соответствии с конфигурацией проекта.
